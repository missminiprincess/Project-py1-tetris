# TETRIS
Простая консольная игра на pygame.
*Функционал включает в себя:
1. Меню.
2. Динамическое изменение скорости игры в зависимости от набранных очков.
3. Функция сохранения рекорда.
4. Количество набранных очков будет зависеть от количества закрытых линий за раз.
* Архитектура:
1. Класс Tetris:
   * Отвечает за управление текущей фигурой, ее движением и поворотом.
   * Инициализирует фигуры, перемещает фигуры вниз и в стороны, также отвечает за вращение фигуры.
2. Класс GameLogic:
   * Отвечает за логику игры, управление скоростью и подсчет очков.
   * Обрабатывает ввод с клавиатуры для перемещения и вращения фигур.
   * Обновляет счет.
     
*Основные функции
1. Инициализация фигур.
2. Проверка границ.
3. Движение фигуры вниз.
4. Вращение.
5. Обновление состояния игры.
